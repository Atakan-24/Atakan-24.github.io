# Portfolio conventions

Read `overview.md` first. Stack: static HTML, CSS, JavaScript and SVG; no build step. Keep German and English editions aligned. Preserve the existing visual system. Public project pages must contain only verified public sources; private customer records and credentials stay out. Describe demos, experiments and source snapshots accurately. Videos use native controls, `preload="none"` and no autoplay. Verify desktop/mobile layout and language-specific links. Changes are local drafts until Atakan authorizes publishing.
