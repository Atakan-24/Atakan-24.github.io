Case study and media collection for Alex, a telephone assistant. The public browser demo guides visitors through a fixed conversation for four trades. Prerecorded speech and sample appointments illustrate a reception workflow.

Visitors can explore the flow from the greeting through a description of the problem to appointment confirmation. The case study also explains how scripted conversations, synthetic voices and HTML scenes were combined into demo videos.

autolm

ProjektgruppeProject group: AutoLM · BranchBranch: master

Experiment zum Bau eines kleinen Sprachmodells von Grund auf. Das Repository verbindet Lehrschritte für Backpropagation und Attention mit einem PyTorch-Transformer, BPE-Tokenizer, Training und einer messbaren Aufgabe: n8n-Workflow-Gerüste aus Text erzeugen.

Die Arbeit untersucht, welche Teile einer engen Generierungsaufgabe ein kleines eigenes Modell lernen kann. Statt nur Textproben zu zeigen, prüft sie JSON, bekannte Knotentypen, Verbindungen und den Import in n8n. Eine einfache Nachschlagekontrolle dient als Vergleich.

Experiment in building a small language model from scratch. The repository connects lessons on backpropagation and attention with a PyTorch transformer, BPE tokenizer, training code and a measurable task: producing n8n workflow skeletons from text.

The work examines which parts of a narrow generation task a small custom model can learn. Evaluation checks JSON, known node types, connections and n8n import rather than relying on text samples alone. A simple retrieval baseline supplies a comparison.

Funktionen

  • Lehrpfad und fusionierter QKV-Attention-Pfad mit Gleichheitstests.
  • Datenaufbereitung, eigenes BPE, Checkpointing und Trainingsschleife.
  • Vorlagensplits mit Abbruch bei überlappenden IDs oder identischen Testtexten im Training.
  • Versionierte Auswertungsdateien und lokale Demo mit offen ausgewiesenem Best-of-k.

Aufbau und Zusammenarbeit

  • Öffentliche Vorlagen werden in Kurzschrift überführt und für das Training mutiert. Ein eigener Tokenizer erzeugt die Eingabeströme für MiniGPT.
  • Die Demo lädt vorhandene Checkpoints, zieht Modellproben, prüft lokale Tore und rendert lesbare Ausgaben zu Workflow-JSON. Der separate Importprüfer ruft n8n auf.
  • Gespeicherte Ergebnisse vom 12.09.2026 melden für 15 Aufgaben 7/15 gültige Antworten bei einem Versuch und 15/15 mit Best-of-8. Das sind Ergebnisse dieses Versuchsaufbaus.

gh-radar

ProjektgruppeProject group: gh-radar · BranchBranch: main

Python-Digest für GitHub-Aktivität: offene Rückfragen in eigenen Repositorys und begründete Vorschläge für Beiträge in anderen Projekten. Das Werkzeug liest GitHub und schreibt einen Bericht. Die HTTP-Schicht lehnt andere Methoden als GET ab.

Der Bericht soll übersehene Rückfragen sichtbar machen und eine große Issue-Suche auf wenige passende Kandidaten reduzieren. Menschen entscheiden anschließend, ob und wie sie tätig werden. Zustand zwischen Läufen verhindert ständig wiederholte Vorschläge.

Python digest of GitHub activity: outstanding questions in owned repositories and explained contribution suggestions elsewhere. The tool reads GitHub and produces a report. Its HTTP layer rejects methods other than GET.

The digest aims to surface missed questions and reduce broad issue searches to a few suitable candidates. People then decide whether and how to act. State between runs prevents constant repetition of suggestions.

Funktionen

  • Eigene Repositorys beobachten und externe Issues nach Ausschlüssen bewerten.
  • Jeder Vorschlag enthält Gründe, Warnungen und eine einfache Aufwandsklasse.
  • Sprachen aus zugänglichen Repositorys erkennen oder per Option festlegen.
  • Text-, JSON- und vollständig netzloser Dry-run-Modus.

Aufbau und Zusammenarbeit

  • __main__.py orchestriert watch und scout, verwaltet Zustand und übergibt Ergebnisse an report.py.
  • Netzwerkzugriffe laufen über github.py. Der Request-Einstieg akzeptiert nur GET und behandelt Drosselung getrennt von leeren Ergebnissen.
  • score.py trennt harte Ausschlüsse von gewichteten Heuristiken. Die Dokumentation meldet 58 Tests; diese Prüfung hat sie nicht ausgeführt.

Einstieg

Rendert die im Code enthaltenen Beispieldaten ohne Netzwerk oder GitHub-Token.
