Windows Screen Time Manager ↗

Screen-time limits and a parental lock for Windows. A SYSTEM scheduled task counts the time, the lock screen shows up in the active user session, and the settings are protected with permissions and salted PIN hashes. PowerShell, Win32 and .NET, with a live demo video.

Systems · Sales

Lead intelligence

Need, budget and reachability scored apart from a separate ICP-fit score. Several sources merged into one profile, with confidence reported separately from freshness. Hiring, ad-spend and tech-stack signals read from pages already fetched.

Systems · Calls

Call handling

Calls split into customer and agent channels before transcription. AI coaching sits behind human approve, edit or reject, with blind grading. A legal calling-hours check stays separate from scoring, and inbound calls fall back to voicemail by a server-side lock.

Systems · Outreach

Outreach and experiments

An email warm-up ramp and a queued LinkedIn channel, with measured numbers labelled apart from self-reported ones. Test cohorts are locked out of production automation, and the weekly niche focus follows measured success rates.

Systems · AI

Agent control

MCP servers exposing read-only business data. A Telegram approval step before any money, access or direction decision, a scored model and effort routing policy, and a watchdog that checks whether the checker is still alive.

Systems · Workflow

Multi-machine agent sync

One shared memory for Claude Code and Codex across macOS, Linux and Windows, with Git backups every 15 minutes.
